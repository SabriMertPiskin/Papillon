# Setup

## Clone Repo
```bash
git clone https://github.com/SabriMertPiskin/Papillon
cd Papillon
```

For the backend and database setup, view the README.md under the backend folder.
For the frontend setup, view the README.md under the frontend folder.

## Selenium E2E Tests

The project includes Selenium end-to-end tests for the main browser flows such as authentication, dashboard navigation, profile settings, security tools, malware upload UI, route protection, and optional cPanel integration.

See `tests/selenium/README.md` for setup, environment variables, and run commands.
